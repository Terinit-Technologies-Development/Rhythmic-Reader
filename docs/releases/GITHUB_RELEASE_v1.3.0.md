Direct Android APK for internal use; this public repository makes release assets
publicly downloadable. No Play Store binary or submission is included. Reader
remains the local outward-attention evidence authority;
Rhythmic Routine remains the only cooldown and re-entry policy authority.

### Highlights

- Routine preview Protocol 2 distinguishes CD3 baseline from CD4+ restorative
  targets while retaining Daily Evidence V2 for CD3.
- CD3 uses 3600 verified seconds plus 36 qualified pages for the requested
  local date.
- Bound Recovery Session V1 is retained for CD4+ at 1800 seconds plus 11
  qualified pages, tied to the exact session and gate.
- Daily Evidence V2 and bound recovery remain isolated evidence roles; there is
  no hidden cumulative Reader debt.
